# سلك — طباعة USB من أندرويد

تطبيق أندرويد يطبع **الصور** و**ملفات PDF** من الجوال إلى الطابعة عبر **كابل USB** مباشرة، بدون واي فاي وبدون رفع الملف إلى أي خادم. التطبيق لا يطلب صلاحية الإنترنت.

## ١٫١ — HP LaserJet P2035

هذه الطابعة تتحدث **PCL 5e** فقط. الإصدار الأول كان يرسل PDF افتراضيًا، والطابعة تتجاهله ولا تسحب ورقة.

في ١٫١:

- زر **اختبار الطباعة المباشرة** يرسل مهمة PCL 5e نصية: `SILK USB TEST` ثم `HP LASERJET P2035` ثم Form Feed.
- الإرسال يتم إلى واجهة USB Printer Class (class 7) وBulk OUT فقط، مع `claimInterface` وSOFT_RESET ونقل مجزأ.
- الشاشة تعرض «تم إرسال X من Y بايت». اكتمال النقل لا يعني خروج الورقة.
- شاشة **تشخيص USB** وزر **نسخ تقرير التشخيص**.

لم تُختبر الطباعة على جهاز حقيقي داخل بيئة البناء. المطلوب على الهاتف: تثبيت ١٫١ فوق النسخة السابقة، ثم «اختبار الطباعة المباشرة»، ثم نسخ التقرير إذا لم تخرج ورقة.

## التثبيت

1. من [الإصدارات](https://github.com/aalbahrii999/silk-usb-print/releases/latest) حمّل `silk-usb-print.apk`.
2. افتح الملف على الجوال واسمح بالتثبيت من هذا المصدر.
3. صل الطابعة بكابل USB. إذا كان منفذ الجوال USB-C ومنفذ الطابعة USB-B فاستخدم كابل OTG أو كابل طابعة USB-C.
4. بعض أجهزة سامسونج وغيرها تحتاج تفعيل **OTG** من الإعدادات.
5. افتح **سلك** ← **اتصال** ← اختر صورة أو مستنداً ← **اطبع الآن**.

عند توصيل طابعة مدعومة قد يفتح التطبيق وحده.

## طرق الطباعة

| الطريقة | متى تستخدمها |
|---|---|
| PDF مباشر | HP وBrother وكثير من طابعات المكاتب. يُبقي الألوان والنص كما هو. |
| PCL رمادي | طابعات الليزر الأقدم التي تفهم PCL5. الصورة تُطبع رمادياً بتظليل. |
| حرارية ٨٠ / ٥٨ | طابعات الإيصالات (ESC/POS) عبر USB. |
| نافذة أندرويد | طابعات إبسون وكانون المنزلية، أو أي طابعة لها إضافة طباعة مثبتة (Mopria أو إضافة الشركة). |

صفحة **تجريبية** داخل التطبيق تكفي لفحص الكابل قبل اختيار ملف.

## حدود صادقة

لا توجد لغة واحدة تتحدث بها كل الطابعات. سلك يرسل عبر منفذ USB الخاص بالطابعة (صنف USB 7 أو الشركات المعروفة) بإحدى اللغات أعلاه. إذا خرجت ورقة فارغة أو لم تطبع:

- بدّل الطريقة. ابدأ بـ PDF مباشر ثم PCL ثم نافذة أندرويد.
- طابعات الحبر المنزلية من إبسون وكانون غالباً لا تقبل PDF/PCL الخام، وتحتاج إضافة الشركة من متجر بلاي مع «نافذة أندرويد».
- الجوال لازم يدعم USB Host (OTG).
- المستندات حتى ٢٠ صفحة في وضع PCL، و٣ صفحات على الحرارية، والملف حتى ٤٠ م.ب.

## البناء من المصدر

يحتاج JDK 17 وAndroid SDK: `platforms;android-34` و`build-tools;34.0.0`.

```bash
export ANDROID_SDK_ROOT="$HOME/Android/Sdk"
bash scripts/build-apk.sh
```

الملف الناتج: `dist/silk-usb-print.apk`.

التوقيع المرفق مفتاح تصحيح شخصي (`signing/debug.keystore`، كلمة المرور `silk-debug-key`) حتى تُثبَّت التحديثات فوق النسخة السابقة. ليس مفتاح نشر لمتجر.

## الخصوصية

الملف يُقرأ على الجوال ويُرسل إلى الطابعة عبر الكابل فقط. لا حساب، لا تحليلات، لا إنترنت.
